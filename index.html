How the checklist works

Each posting is checked against ten questions — asks for a fee up front, pushes contact off-platform, wants sensitive data, pay-per-task gig, vague employer, and so on — plus a scam-type classification. Both models answer all of them in one pass and return a confidence for each, no free text generated.
